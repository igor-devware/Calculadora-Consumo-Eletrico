## 📌 Sobre o Projeto

Este programa foi desenvolvido como parte de uma atividade de iniciação em tecnologia. O objetivo é ajudar o usuário a estimar o consumo mensal de energia elétrica de qualquer aparelho doméstico, além do custo aproximado na conta de luz.

---

## 🐍 Linguagem Utilizada

- **Python 3.x**

---

## 🔢 Fórmula do Cálculo

```
consumo_mensal (kWh) = (potência_W × horas_por_dia × 30) ÷ 1000
```

Para o custo estimado, o consumo é multiplicado pela tarifa de **R$ 0,75 por kWh**.

---

## ▶️ Como Executar

1. Certifique-se de ter o **Python 3** instalado na sua máquina.
2. Clone este repositório:
   ```bash
   git clone https://github.com/seu-usuario/consumo-energia.git
   ```
3. Acesse a pasta do projeto:
   ```bash
   cd consumo-energia
   ```
4. Execute o programa:
   ```bash
   python app.py
   ```

## 💡 Exemplo de Uso

```
Nome do aparelho: Geladeira
```
